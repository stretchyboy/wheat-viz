🚀 SETUP (First Time Only)
───────────────────────────────────────────────────────────────
  ./setup.sh
  
  OR manually:
  1. python3 download_wheat_data.py    # Download data
  2. python3 process_data.py           # Process into JSON


📖 USAGE
───────────────────────────────────────────────────────────────
  Interactive:
    1. Open: output/index.html
    2. Select crop + country
    3. Click "Visualize"
  
  Direct Links:
    output/index.html?crop=wheat&country=world
    output/index.html?crop=rice&country=china
    output/index.html?crop=coffee&country=brazil


✨ FEATURES
───────────────────────────────────────────────────────────────
  ✓ Full-screen video with color filtering
  ✓ Handdrawn graph overlay (Rough.js)
  ✓ Real-time data animation
  ✓ Shareable URLs
  ✓ All crops from FAOSTAT (1961-2025)
  ✓ Smart data caching


🎨 WHAT YOU'LL SEE
───────────────────────────────────────────────────────────────
  • Full-screen crop timelapse video
  • Video color changes based on import price
  • Handdrawn graph animating over time
  • Current year, price, and quantity displayed
  • Smooth animations synced to video

🎛️ CONTROLS (During Visualization)
───────────────────────────────────────────────────────────────
  Change Selection → Return to crop/country selector
  Fullscreen       → Toggle fullscreen mode
  Video Controls   → Pause/play/seek


💡 TIPS
───────────────────────────────────────────────────────────────
  • Data downloads once and caches (saves time!)
  • Use direct URLs to share specific visualizations
  • Graph roughness can be adjusted in visualization.js
  • Works best in Chrome/Firefox
  • Fullscreen mode for best experience


🐛 TROUBLESHOOTING
───────────────────────────────────────────────────────────────
  Data not found?
    → Run: python3 process_data.py
  
  Video not playing?
    → Check: videos/ directory has .mp4 file
    → Try different browser
  
  Download failed?
    → Check internet connection
    → Try again (might be temporary API issue)
  
  Graph not showing?
    → Check browser console (F12)
    → Verify Rough.js loaded from CDN


📊 DATA INFO
───────────────────────────────────────────────────────────────

  Years:   1961-2025
  Metrics: Import/Export Price & Quantity

  Areas:   All countries + regions
